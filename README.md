# Maze Solver

A C++ project for generating and solving mazes while exploring data structures and pathfinding algorithms.

## Current status

🚧 Work in progress

The project is currently in the initial development stage.

## Planned Features

- [] Represent a maze using a 2D array
- [] Generate random mazes
- [] Define start and end positions
- [] Implement maze traversal
- [] Implement BFS pathfinding
- [] Implement DFS pathfinding
- [] Reconstruct and display the path
- [] Compare BFS and DFS
- [] Add maze/pathfinding visualization
- [] Improve maze generation to guarantee a solution
- [] Experiment with A* pathfinding

## Technologies

- C++
- Git / GitHub

## Concepts

This project is being developed while studying:

- Arrays
- 2D arrays
- Stacks
- Queues
- Trees
- Graph traversal
- Breadth-First Search (BFS)
- Depth-First Search (DFS)
- Pathfinding algorithms

## Goal

The goal of this project is to build a practical understanding of data structures and pathfinding algorithms by implementing them from scratch rather than relying entirely on the c++ standard library.
